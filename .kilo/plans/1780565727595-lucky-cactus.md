## Задача 10: Отзыв только после получения

**Где менять:** `app/views/products/show.html.erb:143`

**Сейчас:**
```erb
<% if user_signed_in? && current_user.orders.joins(:order_items).where(order_items: { product_id: @product.id }).exists? %>
```

**Надо:**
```erb
<% if user_signed_in? && current_user.orders.joins(:order_items).where(order_items: { product_id: @product.id }, status: :delivered).exists? %>
```

Контроллер (`ReviewsController#create`) уже проверяет `status: :delivered`. Вьюха отстаёт — форма отзыва показывается даже для неполученных заказов. Нужно синхронизировать условие.

## Задача 8: Перевод "Shipping address"

**Где менять:** `config/locales/ru.yml`

**Сейчас:** В файле уже есть переводы:
```yaml
activerecord:
  attributes:
    order:
      shipping_address: "Адрес доставки"
  errors:
    models:
      order:
        attributes:
          shipping_address:
            blank: "не может быть пустым. Укажите адрес доставки"
```

**Проблема:** Пользователь видит "Shipping address не может быть пустым" вместо "Адрес доставки не может быть пустым. Укажите адрес доставки". Это значит, что перевод атрибута `shipping_address` не подхватывается.

**Надо проверить:**
1. Корректность YAML-синтаксиса (возможно, проблема с отступами)
2. Загружается ли YAML-файл (перезапустить сервер)
3. Не переопределён ли `errors.full_message` где-то в коде

**Если проблема не в YAML — добавить явный вызов `I18n.t` в `orders/new.html.erb`:**
```erb
<% @order.errors.full_messages.each do |msg| %>
  <!-- заменить msg на переведённый вариант -->
<% end %>
```
Либо переписать на русском вручную в `new.html.erb`:
```erb
<% @order.errors.each do |error| %>
  <li><%= t("activerecord.attributes.order.#{error.attribute}") %> <%= error.message %></li>
<% end %>
```

**Надо:** В `create` и `update` добавить авто-расчёт:
```ruby
if product_params[:stock_by_size].present?
```

## Задача 7: "Не оценённые товары" в профиле

**Где менять:**
- `app/controllers/profiles_controller.rb` — добавить `@unreviewed_products`
- `app/views/profiles/show.html.erb` — добавить блок

**Что сделать:**
```ruby
# profiles_controller.rb
def show
  @user = current_user
  @orders = @user.orders.includes(:order_items).order(created_at: :desc).limit(5)
  @unreviewed_products = Product
    .joins(order_items: :order)
    .where(order_items: { orders: { user_id: @user.id, status: :delivered } })
    .where.not(id: @user.reviews.select(:product_id))
    .distinct
    .limit(10)
end
```

**Вьюха:** Добавить третий блок (колонку) в профиле:
```erb
<div class="bg-white rounded-lg p-5 shadow-[0_2px_8px_rgba(0,0,0,0.06)]">
  <h2 class="mt-0 mb-4">Оцените товары</h2>
  <% @unreviewed_products.each do |product| %>
    <div class="flex items-center gap-3 py-2 border-b border-[#eee] last:border-b-0">
      <%= link_to product.name, product_path(product), class: "text-sm text-accent hover:underline" %>
      <span class="text-xs text-[#888]"><%= product.display_final_price %> ₽</span>
    </div>
  <% end %>
  <% if @unreviewed_products.empty? %>
    <p class="text-[#888] text-sm">Все товары оценены</p>
  <% end %>
</div>
```

### 1b. Фильтрация `cart_items` по `cart_item_ids`

**Где менять:** `app/controllers/orders_controller.rb` — `ensure_cart_not_empty` + `create`

**Надо:**
```ruby
def ensure_cart_not_empty
  @cart = current_cart
  @cart_items = @cart.cart_items.includes(product: { images_attachments: :blob })

  if params[:cart_item_ids].present?
    @cart_items = @cart_items.where(id: params[:cart_item_ids])
  end

  if @cart_items.empty?
    redirect_to cart_path, alert: "Корзина пуста. Выберите товары для заказа."
  end
end
```
