## Задача 1: Фоновые картинки для карточек категорий на главной

**Где менять:**
- `app/views/pages/about.html.erb` (Rails, строки 62-77)
- `frontend/app/page.tsx` (Next.js, строки 89-135)

**Что сделать:**
- В Rails-вьюхе: заменить сплошной `bg-[#1a1a1a]` на `bg-[#1a1a1a]` + `bg-gradient-to-br` с цветовой вариацией по `cat.id`, и добавить фоновый SVG-паттерн/иконку с низкой opacity (как в Next.js версии)
- В Next.js: уже есть SVG-иконки с opacity, но фоновый цвет меняется только точечно. Улучшить — добавить градиенты и узоры, чтобы карточки выглядели более тематическими (одежда/мода)
- Использовать маппинг названий категорий на SVG-path для иконок одежды (платье, рубашка, брюки, куртка, аксессуары и т.д.)

## Задача 5: Возможность заказать один товар из корзины

**Где менять:**
- `app/views/carts/show.html.erb` (Rails, строки 20-54)
- `app/controllers/orders_controller.rb` (Rails, уже поддерживает `single_item_id` в API, но не в HTML)
- `frontend/app/cart/page.tsx` (Next.js) — уже есть `buyNow` функция (строки 55-70)

**Что сделать:**
- В Rails `orders_controller.rb`: добавить поддержку `params[:single_item_id]` в метод `create`, аналогично API-контроллеру
- В Rails `carts/show.html.erb`: добавить кнопку "Купить сейчас" в каждой строке товара (рядом с кнопкой "Удалить"), которая отправляет `single_item_id`
- В Rails `orders/new.html.erb` и `orders_controller#new`: если передан `single_item_id`, показывать только этот товар
- Альтернативно: сделать кнопку "Купить сейчас", которая сразу создаёт заказ (как в Next.js версии), минуя страницу оформления
